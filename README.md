# 奶龙发疯事务所

一个使用五款 3D 奶龙模型制作的 60 秒恶搞街机小游戏。

**[公网试玩](https://Wang-bot-cmd.github.io/nailong-chaos-club/)**

## 全息科幻版 2.0

- 全息扫描地台、轨道能量环、漂浮晶体和星尘。
- 奶龙传送扫描、闪现拖尾、能量护盾、大招光柱与空间扭曲。
- 原有五种造型及参考图配色，角色使用独立中性光照。
- 手机多指同时移动和攻击，按住连续攻击，闪现冷却显示。
- 适配横竖屏、安全区及小屏，支持浏览器全屏功能。
- 自适应 / 超频 / 轻量画质，手机限制像素倍率和粒子数量，掉帧时自动降低开销。
- 首屏只加载默认造型，其他造型后台加载；实体复用，合并小物体几何，固定步长模拟，HUD 限频更新。
- 遵循减少动态效果设置；切后台自动暂停。

## 开始玩

直接打开上方公网地址。另附离线单文件 HTML，可以在 Chrome 或 Edge 中离线游玩。

也可以双击 **启动游戏.cmd**。电脑需要安装 Node.js；它会启动本地网页并打开浏览器。游戏期间保留窗口，关闭窗口结束服务。

## 玩法

- WASD / 方向键移动；手机拖动左下摇杆。
- 鼠标点击 / J：创飞附近的班味公文包。
- 空格 / Shift / 鼠标右键：闪现，短暂无敌并撞飞班味。
- Q / 底部发疯按钮：能量满时清场，并短暂无敌。
- Esc / P：暂停。
- 奶茶增加快乐值和能量，连续得分有连击奖励。4 秒不得分会断连。
- 坚持 60 秒成功下班；被撞三次就会被抓去上班。最高纪录保存在当前浏览器。
- 右上角 ♪ 可以开关合成音乐和音效。

## 模型与配色

五个模型均来自用户提供的 STL。原文件保持不变。
已统一比例与朝向、优化几何，并把参考照片采样的颜色保存到 GLB 模型的顶点颜色中，使用 16 位颜色存储。

| 部位 | sRGB 参考色 |
|---|---|
| 手掌、脚掌 | #313536 |
| 绿色眼圈 | #419755 |
| 黑色瞳孔 | #050706 |
| 身体 | #F5C631 |
| 肚皮 | #ECD19E |

游戏内角色使用固定的中性光照，避免舞台的彩色灯光改变其配色。照片同一部位包含明暗变化，游戏也保留立体明暗；色表记录的是从照片提取的基准色。
奶蛋没有手脚，因此只调整其现有部位。

`public/models` 是带颜色的独立 GLB 模型；`docs` 是 GitHub Pages 发布内容，`dist` 是本地构建产物。

## 继续开发

安装 Node.js 20.19+ 或 22.12+，运行 `npm install`，然后 `npm run dev`。
`npm run build` 会进行 TypeScript 检查并生成 `dist`。

游戏采用 Three.js + TypeScript + Vite；运行时没有外部 AI 或在线接口调用。音效由本地 Web Audio 合成。

## 验证

TypeScript 与正式构建通过。Chromium 中验证了五只角色、移动得分、大招、暂停、胜负与重开、真实多触点输入、按住连续攻击、320–430 像素竖屏与 844 像素横屏布局、画质切换及减少动态效果。响应式测试使用浏览器设备模拟，不等同于每一款实体手机的性能保证。
